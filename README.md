# California least tern (*Sternula antillarum browni*) ocean, diet, and reproduction analysis
A repository to recreate the analysis in the Mills et al. (in prep) publication examining the influence of ocean conditions on California least tern diet and reproductive success.

## Programs needed to run:
* R

## Code files needed to run:
* CLTE_ocean_diet_repro.R

## Data files needed to run:
* SEM_data_yearly.csv
* Hosted on https://urldefense.com/v3/__https://doi.org/10.5281/zenodo.20435101__;!!H7yp__TR!YTbYySw4syOOWDbjLMqonqvCo8O5jtII6OXHb6SuNQK5gJzxR2LNIFUluxJsZ6cfIfIoWTqRyUNdwxb3QXz4HQg$


## Complete the following steps in this order:

1) Open the *SEM_analysis.R* file (all R code will be run from here and line numbers below refer to this file).

2) Load packages (L7-10).

3) Load data (L18-20).

4) Scale all variable (L24-54)

5) Build, run, and examine summaries for piecewise structural equation models (pSEM) (L58-162).
